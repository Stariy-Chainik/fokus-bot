Решение владельца 2026-09-10: бот в MAX нужен **только для родителей** (педагоги, админ,
спортсмены — в Telegram), на тех же Google-таблицах. Реализовано в `bot/max/` (maxapi 1.2,
Python ≥ 3.10 → локальный .venv переведён на 3.12, aiogram поднят до 3.31). Релиз 1: вход
(ссылка группы `max.ru/<bot>?start=g_…`, фамилия, второй ребёнок), счета, оплата (СБП онлайн,
реквизиты + QR + чек → админам в Telegram, наличные). Занятия ребёнка сделаны 2026-09-30
(расписание без денег). Дневник в MAX **не нужен** (решение владельца 2026-09-30) — не предлагать;
email для чеков в MAX не сделан.

Токен `MAX_BOT_TOKEN` владелец создаёт у @MasterBot и вписывает в прод `.env` сам (в чат не
присылать); пока пуст — MAX выключен. Привязку родителей ужесточать **не** стали (решение
владельца). Уведомления родителям идут через `ParentNotifier` (`bot/services/parent_notifier.py`),
адрес `("tg"|"max", id)`, в callback — `123` / `m456`.

**How to apply:** новые рассылки родителям — только через notifier; новые экраны родителя —
через `bot/screens` + `parent_views`, чтобы работали в обоих мессенджерах.

**Уточнение 2026-09-18 (Mini App):** админ и педагоги MAX не пользуются — их кабинеты только в
Telegram. Реализация на уровне MAX понадобится позже и только для родителей: родительский кабинет
Mini App проектировать на транспортно-нейтральных экранах (`bot/screens`), чтобы потом отдать его и
в мини-приложение MAX.
