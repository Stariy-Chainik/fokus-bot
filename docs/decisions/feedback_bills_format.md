Правила для экранов «Счёт ученика»:

1. **На админском экране «Счёт ученика за период»** не показываем статус `🔴 Период не сдан педагогом` в строке педагога.
   **Why:** статус сдачи периода уже виден в разделе «Зарплаты» по каждому педагогу — дублировать не нужно.
   **How to apply:** в `cb_bills_show` в строке педагога оставляем только статус оплаты: `⏳ Счёт не создан / 📋 Ожидает оплаты / ✅ Оплачен (дата)`. Статус оплаты нужен по всем ученикам школы — это единственное место в UI, где виден статус оплаты счёта.

2. **В сообщении родителю** (шаблон из `cb_bill_send`) не пишем статусы «сдан/не сдан» вообще.
   **Why:** родителю это внутренняя кухня школы.
   **How to apply:** в шаблон для родителя включаем: ФИО ученика, название группы, месяц (период можно оставить), ФИО педагога(ов), перечень занятий (дата · длительность · сумма), одно «Итого к оплате». Без статусов.

3. **Родитель платит школе, не педагогу.**
   **Why:** правовая/организационная реальность школы — группировка по педагогу допустима только как внутренняя разбивка в счёте, но итог общий и адресован школе.
   **How to apply:** в шаблоне родителю не формулируем «к оплате педагогу X», только «Итого к оплате: N ₽» в самом конце.
