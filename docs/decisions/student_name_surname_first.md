Правило именования: в поле `Student.name` **фамилия всегда на первом месте**, затем имя (и опциональный суффикс — номер подгруппы, пометка и т.п.).

Примеры: `"Василенко Вероника 27"`, `"Добрянский Глеб"`, `"Вергер Алексия"`.

**Why:** единый формат для сортировки, поиска и сопоставления имён из внешних Google-таблиц (в них встречается тот же порядок — «Фамилия Имя»).

**How to apply:**
- При сопоставлении имён из внешних таблиц с базой — первичный ключ = **первое слово** (фамилия), лояльно к остатку (отчество, номер группы, %, пометки). Полное совпадение не искать.
- При создании нового ученика — если пользователь ввёл «Имя Фамилия», переспросить/переставить. Не добавлять в базу в обратном порядке.
- Дубль-чек по фамилии: если в базе уже есть `{Фамилия} …`, считать его кандидатом на совпадение даже если имя/суффикс отличается — показать пользователю список, не создавать молча.
- Исключение: иностранные имена из одного слова (редко) — можно без фамилии, но это exception, не норма.
