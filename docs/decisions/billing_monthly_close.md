PER_VISIT группы (GRP-0007 Детский Сад ЮБ, GRP-0008 Детский Сад БП) тарифицируются за каждое посещение; окончательный счёт за месяц клиенту выставляется **в конце месяца** после последнего занятия.

**Why:** клиент оплачивает фактическое посещение за месяц одним платежом. Внутри месяца — только накопление `Lesson.attendees`, сумма растёт по мере добавления занятий.

**How to apply:**
- Если добавляешь/корректируешь lesson-записи в середине месяца — это промежуточное состояние, не финальный счёт.
- Не предлагай «отправить счёт родителю» до закрытия месяца.
- Когда делаешь массовую заливку за прошлый месяц (как апрель 2026) — это уже финальное состояние, можно считать счёт закрытым.
- Пересчёт скидок 10% (см. `docs/todo.md`) для частично закрытых месяцев — корректировать `Lesson.attendees.amount` для конкретных student_id, а не пересоздавать занятия.
