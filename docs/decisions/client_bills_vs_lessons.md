«Занятия» и «Счета» — два разных экрана клиентского меню с разными задачами.

**📅 Занятия** — история посещений. Отвечает на вопрос «что было»:
- список занятий по датам: педагог, длительность, стоимость каждого
- фильтр по дате / месяцу
- нет статуса оплаты, нет кнопки «Оплатить»

**📋 Счета** — финансовый документ. Отвечает на вопрос «сколько должен»:
- агрегат по педагогам за месяц
- статус ⏳ Ожидает / ✅ Оплачен
- в будущем — кнопка 💳 Оплатить (платёжный сервис не подключён)
- список последних 6 месяцев

**Why:** разделение принято осознанно — клиент видит детали в «Занятиях», а платит через «Счета».
**How to apply:** не смешивать логику двух экранов; платёжную кнопку добавлять только в «Счета».
