Любой внешний Google Sheets-файл, который пользователь даёт как источник данных для импорта/сверки, — **только чтение**. Не править ячейки, не дописывать строки, не менять формулы/форматы.

Известные файлы с этим режимом:
- `1qO4NRnluWD_P4iAIEgDSE5OHHIY0ahGV92hK2_ak0zc` — мастер посещений (Контарева Л. и др.), правило зафиксировано 2026-04-23.
- `1gi4H1LLfFEpfFWLcr7-y_S6unu3C-ARpfWMXApRk05o` — расписания педагогов (Река, Лобачев, Дронова и др.), правило зафиксировано 2026-04-25.

**Why:** Эти файлы ведут педагоги/школа вручную — это первичный источник. Правка ботом ломает их поток и создаёт расхождения. Бот должен импортировать данные в свой собственный spreadsheet (`settings.google_sheet_id`), а не мутировать чужой.

**How to apply:** При работе с такими файлами разрешены только read-методы (`ws.get`, `get_all_values`, `row_values`, `fetch_sheet_metadata`). Создавать **новые** листы в чужом файле допустимо **только если пользователь явно попросил** (как лист «Индивидуальные Контарева» 2026-04-23). Любое изменение существующих ячеек/листов — запрещено. Если задача требует «привести файл к состоянию X» — меняем бота, не файл.
