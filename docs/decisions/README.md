# Решения владельца и контекст проекта

Копия заметок ассистента (память Claude Code) — чтобы работу можно было продолжить с любого компьютера
и любым ассистентом. Актуальное описание кода — [CLAUDE.md](../../CLAUDE.md); здесь — *почему* так решено.

Секреты (`.env` прода) в репозиторий не входят: держите локальную копию `.env.prod` в корне проекта
(в `.gitignore`) или снимайте с сервера `scp root@178.104.240.252:/opt/fokus-bot/.env .env.prod`.
