Разделение тарифа по длительности занятия (SHORT 35 мин / FULL 60 мин) применяется **только для групп филиала «Детский Сад»**: GRP-0007 (Детский Сад ЮБ) и GRP-0008 (Детский Сад БП).

**Why:** в детском саду часть детей забирают раньше (короткое занятие), часть остаётся на полное. Это особенность конкретных групп, завязанная на расписании сада. В остальных группах такого деления нет — единая продолжительность и единая цена.

**How to apply:**
- При создании/настройке любой новой группы, кроме детсадовских, `duration_short=0` и `price_short=0`, работает только FULL-тариф.
- В PER_VISIT для обычной группы (напр. GRP-0010 ОФП) — одна цена.
- В Sheets-листах посещений: для ЮБ/БП секций значения `35`/`60` (в минутах), для остальных секций — `1`/пусто (был/не был).
- Не предлагать SHORT для не-детсадовских групп в UI/биллинге.
