Решение от 2026-09-06: фискальные чеки (CloudKassir) пока не подключаем —
`CLOUDKASSIR_PUBLIC_ID` на проде пуст, это осознанно. Телефоны родителей всё
равно собираем при привязке по ссылке группы (пригодятся позже).

План оплат: в личном кабинете родителя (веб/Mini App, см. [[group-abonement-billing]])
прикрутить ЮКассу с оплатой через СБП. Бот-флоу оплат (наличные/реквизиты/СБП
вручную) — переходное решение.

Требование на будущее (2026-09-08): часть родителей хочет оплачивать **каждое
занятие отдельно**. В боте на Sheets не делаем (оплата = N строк, гонки, лимиты).
Реализовать при переходе на Postgres/Mini App через Invoice + InvoiceItem с
payableKey на занятие — модель уже описана в docs/MINIAPP_BUILD.md §«счета».
