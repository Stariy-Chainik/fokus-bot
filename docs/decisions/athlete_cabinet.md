Роль «спортсмен» = ученик спортивной группы (`ATHLETE_GROUP_IDS`, прод: GRP-0001) со своим
Telegram; сам находит себя по фамилии на /start → «Я спортсмен», привязка без одобрения
(админу — уведомление с «Отвязать»). Решения владельца 2026-09-10: темы — список танцев/предметов
ХГ (не свободный текст); оценка педагога 1–5 + комментарий; push: спортсмену — задание и оценка,
родителю — оценка, педагогу — ничего (счётчик «без оценки»). Задание = упражнение + минуты
(«маленький квадрат 5 мин»), живёт до закрытия педагогом. Рейтинг: очки = минуты × оценка,
без оценки — коэффициент 3, фильтр по танцу делит минуты записи поровну между темами.

**Отложено:** транскрибация лекций → задания — «в другом сервисе позже»; в модели задания
оставлено `source=lecture` для импорта. Итоги месяца рассылает `scripts/diary_monthly_results.py`
(таймер 1-го числа).

**How to apply:** при доработках кабинета не менять формулу очков и правило самопривязки без
согласования; тестовый спортсмен — Пупкин STU-0193 (в GRP-0001 добавлен для теста).
