# Fokus Mini App (прототип)

Frontend-прототип без backend. Реализованы каркас, дизайн-токены, mock DataProvider, localStorage-сессия,
стартовые панели ролей и рабочий кабинет родителя: дети, занятия, фильтры, корзина, демонстрационная
оплата и история счетов. Также реализован кабинет педагога: рабочая доска, четыре вида записи занятия,
группы, история, расчёт демо-зарплаты и сдача периода с доменными ограничениями. Кабинет администратора
включает сводку, учеников, педагогов, подтверждение оплат, заявки родителей и финансы месяца.

Визуальное направление кабинета: тёплый светлый интерфейс с коралловым акцентом, кремовым фоном,
белыми карточками и адаптивной навигацией под Telegram Mini App (mobile-first).

Стек: Next.js 16, React 19, TypeScript и Tailwind CSS. Версии выбраны после проверки npm audit;
ветка Next.js 14 из ранней спецификации не используется из-за опубликованных уязвимостей.

## Запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000`.

## Проверки

```bash
npm run typecheck
npm run build
npm test
```

## Ограничения демо

- backend и API отсутствуют;
- Telegram initData не проверяется (phone OTP исключён из плана — целевая платформа только Mini App);
- платежи не выполняются;
- данные хранятся только в localStorage браузера.

Все будущие страницы получают данные через `DataProvider`; `MockDataProvider` можно заменить на
`ApiDataProvider` без переписывания компонентов.
